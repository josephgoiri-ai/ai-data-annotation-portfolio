# AI Response Evaluation Sample

## Project Overview

This sample demonstrates a structured approach to evaluating AI-generated responses for quality, relevance, accuracy, clarity, and instruction-following.

## Evaluation Criteria

| Criterion             | What I Check                                               |
| --------------------- | ---------------------------------------------------------- |
| Relevance             | Does the response directly address the user's request?     |
| Accuracy              | Is the information factually correct?                      |
| Completeness          | Does it adequately answer the request?                     |
| Clarity               | Is the response easy to understand?                        |
| Instruction Following | Did the AI follow the user's requirements?                 |
| Safety                | Does the response avoid inappropriate or harmful guidance? |

## Sample Evaluation

### User Request

"Explain the difference between supervised and unsupervised machine learning."

### AI Response Assessment

**Relevance:** Pass
The response addresses the requested comparison.

**Accuracy:** Pass
The main concepts are correctly explained.

**Clarity:** Pass
The explanation uses straightforward language.

**Completeness:** Pass
It explains the fundamental difference and provides examples.

**Instruction Following:** Pass
The response follows the requested explanation format.

### Overall Assessment

**Rating: High Quality**

The response meets the core evaluation criteria and provides a clear explanation suitable for a general audience.

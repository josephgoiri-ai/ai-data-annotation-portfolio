# Text Classification Sample

## Project Overview

This sample demonstrates a basic text-classification workflow used in AI data annotation.

The goal is to assign a predefined category to each text sample consistently according to annotation guidelines.

## Annotation Categories

* **Positive** — expresses satisfaction or approval.
* **Negative** — expresses dissatisfaction or criticism.
* **Neutral** — provides information without a clear positive or negative opinion.

## Sample Annotations

| Text                                                       | Classification | Reason                                           |
| ---------------------------------------------------------- | -------------- | ------------------------------------------------ |
| "The customer service was excellent and very helpful."     | Positive       | Expresses satisfaction with the service.         |
| "The delivery arrived two days late."                      | Negative       | Reports an unfavorable experience.               |
| "The office opens at 8:00 AM."                             | Neutral        | Provides factual information without an opinion. |
| "I am very happy with the quality of the product."         | Positive       | Clearly expresses satisfaction.                  |
| "The instructions were confusing and difficult to follow." | Negative       | Describes a negative experience.                 |

## Quality-Control Approach

Before submitting annotations, I would:

1. Review the annotation guidelines.
2. Identify the main meaning of each text sample.
3. Apply the correct category consistently.
4. Check borderline cases against the guidelines.
5. Review completed annotations for consistency.
6. Correct identified errors before submission.
